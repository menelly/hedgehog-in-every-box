🦔 hedgehog-in-every-box: the demo

The same little form, twice.

  • broken.html: every bug we could fit from the catalogue, each marked 🐛 in the source.
  • fixed.html: the same form with them fixed, each marked ✅.

And a desktop-app window (a side rail, a ribbon, an export panel, a page calibrator, a toast), with the bugs from a live test-drive of a desktop app that Lumen turned into checks:

  • broken-planner.html: the bugs, each marked 🐛.
  • fixed-planner.html: fixed, each marked ✅.

The test suite runs every helper against both, and checks both directions: the broken one gets caught, the fixed one passes.
